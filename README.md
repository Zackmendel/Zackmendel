## 🚀 Featured Project

### 1. DeFi Fundamentals Engine

**A reproducible analytics pipeline for turning raw decentralized exchange activity into financial and operational metrics.**

🔗 **Repository:** [github.com/Zackmendel/defi_fundamentals_engine](https://github.com/Zackmendel/defi_fundamentals_engine)

The project focuses on transforming Uniswap V3 swap data into structured, testable, and documented datasets that can support deeper analysis of protocol activity and economics.

**What it covers:**

- **Data engineering:** A local analytics workflow using DuckDB and Parquet.
- **Analytics engineering:** A layered dbt transformation pipeline for organizing raw data into analytical models.
- **DeFi metrics:** Trading volume, OHLCV, VWAP, accrued LP fees, modeled protocol revenue, take rate, and active traders.
- **Data quality:** dbt tests and validation checks to improve reliability.
- **Transparency:** Documented methodology and data lineage to make metric definitions and transformations traceable.
- **Visualization:** A Next.js dashboard for exploring the resulting metrics.

**Why it matters:** DeFi metrics are only useful when their definitions, assumptions, and transformations are clear. This project demonstrates my approach to building analytics that are reproducible, testable, and easier to audit.

*Scope note: The implemented pipeline centers on Uniswap V3. Additional Uniswap versions and Aave V3 are areas for further research and development, not completed pipeline integrations.*

## 📈 How I Approach Data

My approach to analytical engineering is built around a few principles:

- **Correctness before conclusions:** Validate the underlying data before trusting the output.
- **Reproducibility:** Prefer workflows that can be rerun and independently checked.
- **Clear definitions:** Document how metrics are calculated and what assumptions they depend on.
- **Traceability:** Make it possible to follow a metric back to its source data and transformations.
- **Practical outcomes:** Build datasets and analytical tools that answer real questions rather than producing numbers without context.
